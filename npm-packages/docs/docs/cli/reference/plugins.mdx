# `npx convex plugins`

Manage Convex plugins for coding agents

## Syntax

```sh
npx convex plugins [options] [command]
```

## Subcommands

- [`npx convex plugins install`](#install) — Install or upgrade the Convex plugin for Claude Code and Codex

## `npx convex plugins install` \{#install}

Installs or upgrades the Convex plugin for Claude Code and Codex, in the
terminal, the desktop app and the VS Code extension:
- Claude Code: convex@claude-plugins-official
- Codex: convex@convex-codex-plugin

Claude Code or Codex is skipped when it isn't installed. Windows isn't
supported yet.

### Syntax

```sh
npx convex plugins install [options]
```
