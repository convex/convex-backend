# `npx convex logout`

Log out of the selected account. Directory selections are preserved.

## Syntax

```sh
npx convex logout [options]
```

## Options

<dl>
<dt>`--account <name>`</dt>
<dd>

Remove only this account's saved credentials

</dd>
<dt>`--all`</dt>
<dd>

Remove all saved account credentials, preserving account selections

</dd>
</dl>
