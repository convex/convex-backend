You may select a hosting region for your Convex deployment to change the
location of your data.

All infrastructure powering your deployment will be hosted in the selected
region.

## Available regions

| Region               | Location              | Pricing                |
| -------------------- | --------------------- | ---------------------- |
| `aws-us-east-1`      | US East (N. Virginia) | Standard               |
| `aws-eu-west-1`      | Europe (Ireland)      | 30% regional surcharge |
| `aws-ap-southeast-2` | Asia Pacific (Sydney) | 30% regional surcharge |
| `aws-ca-central-1`   | Canada (Central)      | 30% regional surcharge |

More regions will be added in the future.

## Pricing

Usage in regions outside the US is billed at 1.3x the standard rate (a 30%
regional surcharge). See the [pricing page](https://www.convex.dev/pricing) for
standard rates and [Limits](/production/state/limits) for per-plan resource
limits.

## Selecting a region

When creating a deployment on the Convex dashboard, you will be prompted to
select a region. You may also choose to set the default region for all of your
team's deployments at this time.

[Visit the team settings page](https://dashboard.convex.dev/team/settings) to
change your team's default region.

You can also select a region from the CLI when creating a deployment:

```sh
npx convex deployment create my-deployment --type prod --region aws-ap-southeast-2
```

Omit `--region` to be prompted, or to use your team's default region if one is
set. `us` and `eu` are accepted as shorthand for `aws-us-east-1` and
`aws-eu-west-1`.

## Migrating between regions

An existing deployment's region cannot be changed. If you need to move your
deployment to a different region, you will need to create a new project or
deployment in the desired region and migrate your data by
[exporting](https://docs.convex.dev/database/import-export/import) and
[importing](https://docs.convex.dev/database/import-export/export) your data
with the Convex CLI.
