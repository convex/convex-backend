## convex-vue

The [`convex-vue`](https://www.npmjs.com/package/convex-vue) npm package is a
Vue.js integration library for Convex. It also powers [convex-nuxt](./nuxt.mdx).

See the [Vue Quickstart](/quickstart/vue.mdx) to get started or the
[convex-vue GitHub page](https://github.com/chris-visser/convex-vue) for more
documentation.

## nuxt-convex-module

The [`nuxt-convex-module`](https://www.npmjs.com/package/nuxt-convex-module) npm
package includes a Vue.js integration library for Convex. It also powers the
package's [Nuxt integration](./nuxt.mdx#nuxt-convex-module).

It is a complete port of the official
[Convex React client](/client/react/overview.mdx): each hook becomes a
[composable](https://vuejs.org/guide/reusability/composables.html) with the same
name and arguments. Query arguments can also be
[refs](https://vuejs.org/guide/essentials/reactivity-fundamentals.html#ref) or
getter functions, and query results are refs.

The port also covers the [Clerk](/auth/clerk.mdx) and [Auth0](/auth/auth0.mdx)
adapters and the [Polar](https://www.convex.dev/components/polar) component's
client.

On top of the official client, it adds
[file storage](https://nuxt-convex-module.dev/guide/file-storage) composables
with upload progress, queues and retries, and a `<ConvexImage>` component.

Its `nuxt-convex-module/vue` entry point works in Vue.js apps without Nuxt. See
the [plain Vue guide](https://nuxt-convex-module.dev/guide/plain-vue) to get
started or the [nuxt-convex-module docs](https://nuxt-convex-module.dev) for
more documentation.
