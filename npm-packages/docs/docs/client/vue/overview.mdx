[Vue](https://vuejs.org/) is an "approachable, performant and versatile
framework for building web user interfaces."

## convex-vue

The community-maintained
[`convex-vue`](https://www.npmjs.com/package/convex-vue) npm package is a Vue.js
integration library for Convex. It also powers [convex-nuxt](./nuxt.mdx).

See the [Vue Quickstart](/quickstart/vue.mdx) to get started or the
[convex-vue GitHub page](https://github.com/chris-visser/convex-vue) for more
documentation.

<Admonition type="info">

The [`convex-vue` library](https://github.com/chris-visser/convex-vue) is
community-maintained. Thank you to the maintainer
[Chris Visser](https://github.com/chris-visser) for his work on this project!

You're welcome to ask questions about the library on the
[Convex Discord](https://convex.dev/community) but opening a
[convex-vue GitHub](https://github.com/chris-visser/convex-vue) issue is a
better way to request a new feature or report a bug.

</Admonition>

## nuxt-convex-module/vue \{#nuxt-convex-module-vue}

The `nuxt-convex-module/vue` entry point of the
[`nuxt-convex-module`](https://www.npmjs.com/package/nuxt-convex-module) npm
package is a Vue.js integration library for Convex that works without Nuxt. It
also powers the package's [Nuxt integration](./nuxt.mdx#nuxt-convex-module).

See the [plain Vue guide](https://nuxt-convex-module.dev/guide/plain-vue) to get
started or the [nuxt-convex-module docs](https://nuxt-convex-module.dev) for
more documentation.

It ports the official [Convex React client](/client/react/overview.mdx), with
some additions. The port also covers the [Clerk](/auth/clerk.mdx) and
[Auth0](/auth/auth0.mdx) adapters and the
[Polar](https://www.convex.dev/components/polar) component's client.

Beyond the port, it adds a `<ConvexImage>` component and
[file storage](https://nuxt-convex-module.dev/guide/file-storage) composables
with upload progress, queues and retries.

<Admonition type="info">

The [`nuxt-convex-module` library](https://github.com/qruto/nuxt-convex-module)
is community-maintained by [Slava Razum](https://github.com/slavarazum).

You're welcome to ask questions about the library on the
[Convex Discord](https://convex.dev/community) but opening a
[nuxt-convex-module GitHub](https://github.com/qruto/nuxt-convex-module/issues)
issue is a better way to request a new feature or report a bug.

</Admonition>
