[Vue](https://vuejs.org/) is an "approachable, performant and versatile
framework for building web user interfaces."

The following npm packages integrate Convex with Vue.

<Admonition type="info">

Both libraries are community-maintained. Thank you to their maintainers,
[Chris Visser](https://github.com/chris-visser) (`convex-vue`, `convex-nuxt`)
and [Slava Razum](https://github.com/slavarazum) (`nuxt-convex-module`), for
their work!

You're welcome to ask questions about them on the
[Convex Discord](https://convex.dev/community) but opening a GitHub issue is a
better way to request a new feature or report a bug.

</Admonition>

## convex-vue

The [`convex-vue`](https://www.npmjs.com/package/convex-vue) npm package is a
Vue.js integration library for Convex. It also powers [convex-nuxt](./nuxt.mdx).

See the [Vue Quickstart](/quickstart/vue.mdx) to get started or the
[convex-vue GitHub page](https://github.com/chris-visser/convex-vue) for more
documentation.

## nuxt-convex-module

The [`nuxt-convex-module`](https://www.npmjs.com/package/nuxt-convex-module) npm
package includes a Vue.js integration library for Convex. It also powers the
package's [Nuxt integration](./nuxt.mdx#nuxt-convex-module).

It is a complete port of the official
[Convex React client](/client/react/overview.mdx). Each hook becomes a
composable with the same name and arguments. Arguments can also be refs or
getters, and results such as query data are returned as refs.

Its `nuxt-convex-module/vue` entry point works in any Vue.js app without Nuxt.
See the [plain Vue guide](https://nuxt-convex-module.dev/guide/plain-vue) to get
started or the [nuxt-convex-module docs](https://nuxt-convex-module.dev) for
more documentation.
