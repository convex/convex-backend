[Nuxt](https://nuxt.com/) is a powerful web framework powered by Vue.

Two npm packages integrate Convex with Nuxt.

<Admonition type="info">

Both libraries are community-maintained. Thank you to their maintainers,
[Chris Visser](https://github.com/chris-visser) (`convex-vue`, `convex-nuxt`)
and [Slava Razum](https://github.com/slavarazum) (`nuxt-convex-module`), for
their work!

You're welcome to ask questions about them on the
[Convex Discord](https://convex.dev/community) but opening a GitHub issue is a
better way to request a new feature or report a bug.

</Admonition>

## convex-nuxt

The [`convex-nuxt` npm package](https://www.npmjs.com/package/convex-nuxt)
provides deep integration of Convex with the Nuxt 3 ecosystem.

It uses [convex-vue](./overview.mdx#convex-vue) under the hood.

See the [Nuxt Quickstart](/quickstart/nuxt.mdx) to get started or the
[convex-nuxt GitHub page](https://github.com/chris-visser/convex-nuxt) for more
documentation.

## nuxt-convex-module

The
[`nuxt-convex-module` npm package](https://www.npmjs.com/package/nuxt-convex-module)
provides integration of Convex with the Nuxt 4 ecosystem. It ports the Convex
React and Next.js clients: hooks become auto-imported composables with the same
names, arguments and return shapes, and `preloadQuery` and `fetchQuery` work as
in [Next.js server rendering](/client/nextjs/app-router/server-rendering.mdx).
It also includes integrations for Better Auth, Clerk, Auth0 and Polar.

It uses its own [Vue.js integration library](./overview.mdx#nuxt-convex-module)
under the hood.

See the
[installation guide](https://nuxt-convex-module.dev/getting-started/installation)
to get started or the
[nuxt-convex-module GitHub page](https://github.com/qruto/nuxt-convex-module)
for more documentation.
