[Nuxt](https://nuxt.com/) is a powerful web framework powered by Vue.

Two npm packages integrate Convex with Nuxt.

<Admonition type="info">

Both libraries are community-maintained. Thank you to their maintainers,
[Chris Visser](https://github.com/chris-visser) (`convex-vue`, `convex-nuxt`)
and [Slava Razum](https://github.com/slavarazum) (`nuxt-convex-module`), for
their work!

You're welcome to ask questions about them on the
[Convex Discord](https://convex.dev/community) but opening a GitHub issue is a
better way to request a new feature or report a bug.

</Admonition>

## convex-nuxt

The [`convex-nuxt` npm package](https://www.npmjs.com/package/convex-nuxt)
provides deep integration of Convex with the Nuxt 3 ecosystem.

It uses [convex-vue](./overview.mdx#convex-vue) under the hood.

See the [Nuxt Quickstart](/quickstart/nuxt.mdx) to get started or the
[convex-nuxt GitHub page](https://github.com/chris-visser/convex-nuxt) for more
documentation.

## nuxt-convex-module

The
[`nuxt-convex-module` npm package](https://www.npmjs.com/package/nuxt-convex-module)
provides integration of Convex with the Nuxt 4 ecosystem. It is a complete port
of the official [Convex React](/client/react/overview.mdx) and
[Next.js](/client/nextjs/app-router/server-rendering.mdx) clients. Each hook
becomes an auto-imported composable with the same name and arguments. Arguments
can also be refs or getters, and results such as query data are returned as
refs. `preloadQuery` and `fetchQuery` work the same way on the server. It also
ports the [Clerk](/auth/clerk.mdx) and [Auth0](/auth/auth0.mdx) adapters and the
clients of the [Better Auth](https://labs.convex.dev/better-auth) and
[Polar](https://www.convex.dev/components/polar) components.

On top of the official clients, it adds features for Nuxt:

- [`useAsyncQuery`](https://nuxt-convex-module.dev/guide/server-and-ssr#useasyncquery-ssr-data-the-nuxt-way)
  and `useAsyncPaginatedQuery` for server rendering with Nuxt data fetching
- [File storage](https://nuxt-convex-module.dev/guide/file-storage) composables
  and a `<ConvexImage>` component
- A Convex tab in [Nuxt DevTools](https://nuxt-convex-module.dev/guide/devtools)
- A
  [Content Security Policy](https://nuxt-convex-module.dev/getting-started/security)
  for your deployment with `nuxt-security`

See the
[installation guide](https://nuxt-convex-module.dev/getting-started/installation)
to get started or the
[nuxt-convex-module GitHub page](https://github.com/qruto/nuxt-convex-module)
for more documentation.
