[Nuxt](https://nuxt.com/) is a powerful web framework powered by Vue.

## convex-nuxt

The community-maintained
[`convex-nuxt` npm package](https://www.npmjs.com/package/convex-nuxt) provides
deep integration of Convex with the Nuxt 3 ecosystem.

It uses [convex-vue](./overview.mdx) under the hood.

See the [Nuxt Quickstart](/quickstart/nuxt.mdx) to get started or the
[convex-nuxt GitHub page](https://github.com/chris-visser/convex-nuxt) for more
documentation.

<Admonition type="info">

The
[`convex-nuxt` library](https://github.com/chris-visser/convex-nuxt/tree/main)
is community-maintained. Thank you to the maintainer
[Chris Visser](https://github.com/chris-visser) for his work on this project!

You're welcome to ask questions about the library on the
[Convex Discord](https://convex.dev/community) but opening a
[convex-nuxt GitHub](https://github.com/chris-visser/convex-nuxt) issue is a
better way to request a new feature or report a bug.

</Admonition>

## nuxt-convex-module

The community-maintained
[`nuxt-convex-module` npm package](https://www.npmjs.com/package/nuxt-convex-module)
integrates Convex with Nuxt 4. It ports the Convex React and Next.js clients:
hooks become auto-imported composables with the same names, arguments and return
shapes, and `preloadQuery` and `fetchQuery` work as in
[Next.js server rendering](/client/nextjs/app-router/server-rendering.mdx). It
also includes integrations for Better Auth, Clerk, Auth0 and Polar.

See the
[installation guide](https://nuxt-convex-module.dev/getting-started/installation)
to get started or the [nuxt-convex-module docs](https://nuxt-convex-module.dev)
for more documentation.

<Admonition type="info">

The [`nuxt-convex-module` library](https://github.com/qruto/nuxt-convex-module)

You're welcome to ask questions about the library on the
[Convex Discord](https://convex.dev/community) but opening a
[nuxt-convex-module GitHub](https://github.com/qruto/nuxt-convex-module/issues)
issue is a better way to request a new feature or report a bug.

</Admonition>
