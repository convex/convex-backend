## convex-nuxt

The [`convex-nuxt` npm package](https://www.npmjs.com/package/convex-nuxt)
provides deep integration of Convex with the Nuxt 3 ecosystem.

It uses [convex-vue](./overview.mdx#convex-vue) under the hood.

See the [Nuxt Quickstart](/quickstart/nuxt.mdx) to get started or the
[convex-nuxt GitHub page](https://github.com/chris-visser/convex-nuxt) for more
documentation.

## nuxt-convex-module

The
[`nuxt-convex-module` npm package](https://www.npmjs.com/package/nuxt-convex-module)
provides integration of Convex with the Nuxt 4 ecosystem. It is a complete port
of the official [Convex React](/client/react/overview.mdx) and
[Next.js](/client/nextjs/app-router/server-rendering.mdx) clients. The port also
covers the [Clerk](/auth/clerk.mdx) and [Auth0](/auth/auth0.mdx) adapters and
the clients of the [Better Auth](https://labs.convex.dev/better-auth) and
[Polar](https://www.convex.dev/components/polar) components.

Each hook becomes a
[composable](https://vuejs.org/guide/reusability/composables.html) with the same
name and arguments, and Nuxt
[auto-imports](https://nuxt.com/docs/4.x/guide/concepts/auto-imports) it. Query
arguments can also be
[refs](https://vuejs.org/guide/essentials/reactivity-fundamentals.html#ref) or
getter functions, and query results are refs. The Next.js server helpers, such
as `preloadQuery` and `fetchQuery`, keep their signatures and run in
[server routes](https://nuxt.com/docs/4.x/directory-structure/server).

On top of the official clients, it adds features for Nuxt:

- [`useAsyncQuery`](https://nuxt-convex-module.dev/guide/server-and-ssr#useasyncquery-ssr-data-the-nuxt-way)
  and `useAsyncPaginatedQuery`, which load query data during server rendering
  with
  [Nuxt data fetching](https://nuxt.com/docs/4.x/getting-started/data-fetching)
  and then stay live
- [File storage](https://nuxt-convex-module.dev/guide/file-storage) composables
  that upload with progress, cancellation, queues and retries, and a
  `<ConvexImage>` component
- A
  [`convex-auth` route middleware](https://nuxt-convex-module.dev/components/better-auth#use)
  and a same-origin proxy for Better Auth
- A `dev` script that runs `convex dev` and `nuxt dev` together, and
  [`#convex` aliases](https://nuxt-convex-module.dev/getting-started/configuration#import-aliases)
  for your generated code
- A Convex tab in [Nuxt DevTools](https://nuxt-convex-module.dev/guide/devtools)
- Your deployment's origins in the `nuxt-security`
  [Content Security Policy](https://nuxt-convex-module.dev/getting-started/security)

See the
[installation guide](https://nuxt-convex-module.dev/getting-started/installation)
to get started or the [nuxt-convex-module docs](https://nuxt-convex-module.dev)
for more documentation.
