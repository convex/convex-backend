# Next.js Pages Router quickstart

The finished app from the
[Next.js Pages Router quickstart](https://docs.convex.dev/client/nextjs/pages-router/quickstart-nextjs-pages-router).
The quickstart docs embed `pages/_app.tsx`, `pages/index.tsx`, `convex/tasks.ts`
and `sampleData.jsonl` from this folder, so changes here change the docs.

Run `npm install`, then `npx convex dev` and leave it running. In a second
terminal, run `npx convex import --table tasks sampleData.jsonl` and
`npm run dev`.
